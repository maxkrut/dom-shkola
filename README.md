**Русский** · [English](README.en.md)

Узнайте, какие школы закреплены за адресом, или найдите школу по названию или номеру. Посмотрите закреплённые за ней адреса и ориентировочную территорию на карте. Проект охватывает только Санкт-Петербург.

Сведения о закреплении и фрагменты документов взяты из официальных районных источников.
